# Awesome Malaysia Open Source Projects

A curated list of open-source projects on GitHub made by Malaysian developers or built for the Malaysian market.

Compiled via the GitHub Search API (repositories matching "malaysia" and "malaysian", the topic `malaysia`, the top 50 developers with location set to Malaysia, and known Malaysian organizations), then reviewed by hand. Some entries are general-purpose tools by Malaysian developers; others are specific to the Malaysian market.

## AI, NLP and Machine Learning

- [huseinzol05/Stock-Prediction-Models](https://github.com/huseinzol05/Stock-Prediction-Models) - Machine learning and deep learning models for stock forecasting and trading.
- [mesolitica/NLP-Models-Tensorflow](https://github.com/mesolitica/NLP-Models-Tensorflow) - Tensorflow deep learning models for NLP problems, from Malaysian AI company Mesolitica.
- [malaysia-ai/malaya](https://github.com/malaysia-ai/malaya) - Natural language toolkit for Bahasa Malaysia built on PyTorch, covering sentiment analysis, named entity recognition and text normalisation.
- [malaysia-ai/malaysian-dataset](https://github.com/malaysia-ai/malaysian-dataset) - Aggregated collection of Malaysian datasets from web crawling, social media and translation.
- [malaysia-ai/malaya-speech](https://github.com/malaysia-ai/malaya-speech) - Speech toolkit for Malaysian language, including speech recognition, text to speech and speaker diarisation.
- [cs-chan/Total-Text-Dataset](https://github.com/cs-chan/Total-Text-Dataset) - Scene text dataset by Chee Seng Chan of Universiti Malaya, used in text detection research.
- [cs-chan/Exclusively-Dark-Image-Dataset](https://github.com/cs-chan/Exclusively-Dark-Image-Dataset) - Collection of low-light images for object detection research.
- [cs-chan/ArtGAN](https://github.com/cs-chan/ArtGAN) - GAN implementations for conditional and semantic image synthesis on the WikiArt dataset.
- [mfrashad/text2art](https://github.com/mfrashad/text2art) - Text to image generation tool built with CLIP and VQGAN.
- [UMxYTL-AI-Labs/MalayMMLU](https://github.com/UMxYTL-AI-Labs/MalayMMLU) - Bahasa Melayu multitask benchmark for evaluating large language models, by Universiti Malaya and YTL AI Labs.
- [ariffazil/arifOS](https://github.com/ariffazil/arifOS) - Policy kernel for AI agents that checks tool calls before execution.
- [mesolitica/llm-embedding](https://github.com/mesolitica/llm-embedding) - Finetuned models for embedding tasks in Malaysian context.
- [mesolitica/multimodal-LLM](https://github.com/mesolitica/multimodal-LLM) - Multimodal language modelling with image, audio and text inputs.
- [VanVan120/Malay-to-Code-LLM](https://github.com/VanVan120/Malay-to-Code-LLM) - Research project fine-tuning a language model to generate code from Bahasa Melayu commands.
